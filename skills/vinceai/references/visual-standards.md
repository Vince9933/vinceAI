# 动效与封面参考

## 动效选型

动效应当帮助观众定位证据、理解差异或看懂顺序。把网页的滚动和鼠标触发转换成视频帧与口播落点。

| 方法 | 适用段落 | 实现要点 |
| --- | --- | --- |
| 标题错峰显现 | 开场提出问题 | 小幅上移，由虚变清，留足看清标题的时间 |
| 局部聚光 | 官网截图、产品录屏或文档 | 用对齐的两层图，柔和地聚焦完整引文，保留下层语境 |
| 同框换字 | 同一件事的两个条件或价格变化 | 同一框中顺着口播切换文字，观众无需重新寻找位置 |
| 数字递增 | 有出处和口径的数据 | 快速落到核实的终值，终值和单位驻留 |
| 面板滑入 | 真人讲解接产品演示 | 录屏从边界进入，视情况保留真人画中画 |
| 叠卡 | 连续步骤和逐项对照 | 新一项进入前景，旧项保留顺序关系 |
| 分层视差 | 企业地图或产品图 | 前后层短程差速，地图位置和标签仍易读 |

## 封面

- **高对比信息流。** 用一句问题或一项结果做大标题，把一个主题图形作为视觉焦点。按题材选强调色，使用真实品牌标识时保留其比例并核对出处。缩到约 120 像素宽检查题目与主体是否容易识别。
- **米白杂志。** 米白底、轻纸粒、衬线刊头和克制的红色强调。费用专题可用示意账单，标题明确要解释的那笔费用。避免添加虚构的价格、配额或结论。
- **对照专题。** 可用两张图卡表示两个条件。图形清楚地对应文字，读者能辨认每张卡的对象和口径。
- **真人或纯图文。** 真人从用户可用的实拍中挑自然闭口、视线有落点的片刻，保留必要的拍摄环境。纯图文用一个主题图形加短题。横竖两张分别安排读序、文字断行和元素位置。以正尺寸检查完整文字、标识和平台裁切。
